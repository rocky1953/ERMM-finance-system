一、部署架構總覽

使用者瀏覽器 → IIS 10 :80 / :443
純反向代理（不路由） → Node.js Express :3008
app.js + routes/（全部路由） → MySQL 8 :3306
ermm_db
Redis :6379 / DB 1
會話快取

NSSM 服務：ERMM-Finance（開機自啟 / 崩潰重啟）   MySQL 服務：MySQL80   Redis 服務：Redis   工作排程：每日 02:00 備份
設計原則：IIS 不參與路由分發
IIS 的 web.config 只需一條 Rewrite 規則將所有請求代理到 http://127.0.0.1:3008/。所有 /api/* 路由由 app.js 和 routes/ 資料夾管理。新增功能不需要修改 IIS，只需在 Node.js 層新增路由檔即可。
兩種部署模式：
  • 簡易模式（內網使用）：跳過 IIS，使用者直接訪問 http://伺服器IP:3008。只需完成階段 1~7。
  • 完整模式（對外 / 需要 HTTPS）：IIS 接管 80/443 埠反向代理至 3008。完成全部階段。

三、階段 1：安裝並調優 MySQL 8

1-1. 安裝 MySQL 8.0

下載 MySQL Installer for Windows：dev.mysql.com/downloads/installer

  • 安裝類型選擇 Server only
  • Config Type 選 Server Machine；連線數維持預設或調為 100
  • 埠口 3306，勾選開機自動啟動（Windows Service 名稱預設 MySQL80）
  • Authentication Method 選 Use Strong Password Encryption
  • 設定 root 強密碼並妥善保存

1-2. 建立資料庫與專用帳號

# 建立資料庫（小寫 ermm_db）
mysql -u root -p -e "CREATE DATABASE IF NOT EXISTS ermm_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

# 建立應用專用帳號
mysql -u root -p -e "CREATE USER IF NOT EXISTS 'ermm_app'@'localhost' IDENTIFIED BY 'aaabbb123'; GRANT ALL PRIVILEGES ON ermm_db.* TO 'ermm_app'@'localhost'; FLUSH PRIVILEGES;"

# 驗證帳號可登入
mysql -u ermm_app -p ermm_db -e "SELECT VERSION();"

1-3. 還原資料庫備份

# 將源伺服器的 ERMM_db_full.sql 放到 D:\backup\，然後導入

# 驗證表數量（預期約 22 張）
mysql -u ermm_app -p ermm_db -e "SHOW TABLES;"

編輯 MySQL 設定檔（預設路徑 C:\ProgramData\MySQL\MySQL Server 8.0\my.ini），在 [mysqld] 段加入：

nano # 或用 notepad

max_connections=100

# --- InnoDB（4GB 機器範例）---

十、階段 8：IIS 反向代理 + HTTPS

核心設計原則：IIS 只當純反向代理，路由分發全在 Node.js
IIS 的 web.config 只需一條 <rule> 將所有請求代理到 http://127.0.0.1:3008/。所有 /api/* 路由由 app.js 和 routes/ 資料夾管理。新增功能不需要修改 IIS/web.config，只需在 Node.js 層新增路由檔即可。

路由分發架構

層級檔案職責新增功能是否需改
IISweb.config（URL Rewrite + ARR）反向代理 + HTTPS + 上傳限制不需要
Node.js 入口app.js引入路由檔 + 註冊路徑前綴 + 靜態檔服務加 2 行（require + app.use）
路由邏輯routes/新模組.js定義 GET/POST/PUT/DELETE 端點新增此檔案
前端頁面public/js/pages/新頁面.js呼叫新 API + 渲染 UI新增此檔案

8-1. 建立站台與 web.config

  • 開啟 IIS 管理員（inetmgr）→ 網站 → 新增網站
  • 站台名稱 ERMM-Finance；實體路徑指向空目錄（如 C:\inetpub\ERMM）
  • 繫結：http 埠 80，主機名稱填你的網域
  • 應用程式集區 .NET CLR 版本 選 無 Managed 程式碼

在站台實體目錄建立 web.config：

<?xml version="1.0" encoding="UTF-8"?>
<configuration>
  <system.webServer>
    <rewrite>
      <rules>
        <rule name="ReverseProxyToNode" stopProcessing="true">
          <match url="(.*)" />
          <action type="Rewrite" url="http://127.0.0.1:3008/{R:1}" />
          <serverVariables>
            <set name="HTTP_X_FORWARDED_PROTO" value="https" />
            <set name="HTTP_X_REAL_IP" value="{REMOTE_ADDR}" />
          </serverVariables>
        </rule>
      </rules>
    </rewrite>
    <security>
      <requestFiltering>
        <requestLimits maxAllowedContentLength="52428800" />  <!-- 50MB -->
      </requestFiltering>
    </security>
    <httpProtocol>
      <customHeaders>
        <add name="X-Content-Type-Options" value="nosniff" />
        <add name="X-Frame-Options" value="SAMEORIGIN" />
      </customHeaders>
    </httpProtocol>
  </system.webServer>
</configuration>

8-2. 設定 HTTPS 憑證

方式 A：商用 / 內部 CA 憑證

  • 向 CA 申請憑證，取得 .pfx 檔
  • IIS 管理員 → 伺服器節點 → 伺服器憑證 → 匯入 PFX
  • 站台 → 繫結 → 新增：類型 https、埠 443、選取憑證

方式 B：win-acme 免費 Let's Encrypt（需公開網域 + 80 埠可達）

# 下載 win-acme：https://www.win-acme.com/
# 以管理員執行 wacs.exe，依精靈選 N: 建立新憑證 → 選站台 → 自動驗證並繫結
# 工具會自動設定 443 繫結與到期前自動續期排程

HTTP 強制跳轉 HTTPS（加進 web.config 的 rules 最前面）

<rule name="HTTPtoHTTPS" stopProcessing="true">
  <match url="(.*)" />
  <conditions>
    <add input="{HTTPS}" pattern="^OFF$" />
  </conditions>
  <action type="Redirect" url="https://{HTTP_HOST}/{R:1}" redirectType="Permanent" />
</rule>

十一、階段 9：MySQL 定時備份

9-1. 備份腳本

# 建立 db_backup.ps1
notepad C:\Project\ERMM-finance-system\scripts\db_backup.ps1
# ERMM MySQL 每日備份 + 壓縮 + 保留 14 天
$ErrorActionPreference = "Stop"
$dump = "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysqldump.exe"
$user = "ermm_backup"
$env:MYSQL_PWD = "aaabbb123"
$db   = "ermm_db"
$dir  = "D:\backup\mysql"
$date = Get-Date -Format "yyyyMMdd_HHmm"
$file = Join-Path $dir "ERMM_$date.sql"

New-Item -ItemType Directory -Force $dir | Out-Null

& $dump -u $user --default-character-set=utf8mb4 --single-transaction --routines --triggers $db |
  Out-File -FilePath $file -Encoding utf8

Compress-Archive -Path $file -DestinationPath "$file.zip"
Remove-Item $file

Get-ChildItem "$dir\ERMM_*.zip" |
  Where-Object { $_.LastWriteTime -lt (Get-Date).AddDays(-14) } |
  Remove-Item

Write-Output "[$(Get-Date)] Backup OK: $file.zip"

9-2. 註冊每日排程（管理員 PowerShell）

$action  = New-ScheduledTaskAction -Execute "powershell.exe" `
    -Argument "-NoProfile -ExecutionPolicy Bypass -File C:\Project\ERMM-finance-system\scripts\db_backup.ps1"
$trigger = New-ScheduledTaskTrigger -Daily -At 2:00AM
$principal = New-ScheduledTaskPrincipal -UserId "SYSTEM" -RunLevel Highest
Register-ScheduledTask -TaskName "ERMM-DB-Backup" -Action $action -Trigger $trigger -Principal $principal

# 立即試跑一次
Start-ScheduledTask -TaskName "ERMM-DB-Backup"
Get-ChildItem D:\backup\mysql\

十五、故障排查

症狀 1：服務啟動後立刻停止

Get-Content C:\Project\ERMM-finance-system\logs\service-err.log -Tail 30
# ① Cannot find module → 未執行 npm install 或 AppDirectory 設錯
# ② Access denied for user → .env 密碼錯
# ③ EADDRINUSE :3008 → 埠口被佔：netstat -ano | findstr :3008
# ④ Redis connection refused → Memurai 服務未啟動或密碼錯

症狀 2：Redis 連線失敗

# 確認 Memurai 服務運行
Get-Service Memurai

# 測試連線
redis-cli -a aaabbb123 -n 1 ping
# 若回 NOAUTH → .env 的 REDIS_PASSWORD 與 memurai.conf 不一致
# 若回 Connection refused → Memurai 服務未啟動

症狀 3：3008 埠口被佔用

netstat -ano | findstr :3008
Stop-Process -Id <PID> -Force
Start-Service ERMM-Finance

症狀 4：IIS 回 502.3 / 502.5

Get-Service ERMM-Finance
Invoke-RestMethod http://127.0.0.1:3008/api/health
# 確認 web.config 代理目標與 .env PORT 一致（皆 3008）
# 確認 ARR Proxy 已啟用

症狀 5：Excel 匯入逾時或 413

# 確認 web.config 有：
# maxAllowedContentLength="52428800"（50MB）
# proxy timeout 設為 00:05:00

症狀 6：重開機後服務沒起來

Get-Service ERMM-Finance, MySQL80, Memurai | Select Name, Status, StartType
# 若 StartType 非 Automatic：
Set-Service ERMM-Finance -StartupType Automatic

症狀 7：中文資料亂碼

mysql -u ermm_app -p ermm_db -e "SHOW VARIABLES LIKE 'character%';"
# 確認 character_set_server = utf8mb4
# mysqldump 與 mysql 導入都需帶 --default-character-set=utf8mb4

症狀 8：PowerShell 執行 node 腳本被擋

# 使用 .cmd 版本或直接用 node 執行 .js 檔
node app.js              # 直接執行，不受執行策略影響
npm.cmd install          # 用 .cmd 版本
