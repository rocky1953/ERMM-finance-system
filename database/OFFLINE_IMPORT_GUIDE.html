一、快速開始（5 步）

  1. 打開 Excel 模板：database/finance_data_template.xlsx
  2. 在各 Sheet 的 第 3 行起 貼上你的資料（保留 Row 2 的欄位代碼！）
  3. 存檔（另存新檔也可以，記住路徑）
  4. 在 e:\finance 目錄執行匯入指令
  5. 到系統「批次管線」頁點 一鍵執行全部 重算三大報表 & 風險指標
💡 匯入指令 — 把路徑換成你實際的 Excel 檔： 
cd e:\finance
node database/import_excel.js "你的檔案路徑.xlsx"

六、匯入順序建議

  1. 優先級 1 — 01_財務摘要_summary（三大報表的基礎，最核心）
  2. 優先級 2 — 02~08 日常作業表（順序任意，互不依賴）
  3. 優先級 3 — 到系統「批次管線」頁點 一鍵執行全部 重算：
    • 折舊 / 累計折舊
    • Z-Score / BZ / JZ 風險模型
    • ROE / ROA / 毛利率 / 淨利率 / 資產週轉率
    • 營業活動 / 投資活動 / 籌資活動 現金流量
    • VAT 進項稅額 / 附加稅

七、常見錯誤 Q&A

匯入後前端頁面全是「-」？
檢查該 Sheet 的 Row 2 欄位代碼 是否被你改過。欄位代碼必須與 DB 欄位名完全一致（如 sale_amt, net_profit_amt, sub_amt）。
現金日記賬「收入 / 支出 / 餘額」全是「-」？
檢查 DB_CR 是否正確填 DR / CR（英文大寫 2 字元），以及 sub_amt 是否有正數值。
資產負債表顯示「不平衡」？
檢查 01_財務摘要的資料平衡公式（見 4.1 節）。系統批次管線重算會自動幫你校正。
匯入腳本報 Unknown column 'XXX'？
你的 Row 2 欄位代碼與 DB 欄位名不對。請打開 database/schema.sql 比對，或直接用模板的 Row 2（已驗證）。
如何更新既有資料？
匯入腳本使用 INSERT ... ON DUPLICATE KEY UPDATE，重複主鍵自動覆蓋。匯入相同 bu_no + YYYY_MM 即可更新。
匯入的日期變成 1900-01-01 或 0000-00-00？
Excel 把 0 視為日期 1900-01-01。請不要在日期欄位填 0。模板裡空日期欄位已留空白，匯入腳本也會自動清洗這兩種異常日期。
同一批資料可以重複匯入嗎？
可以。腳本有 ON DUPLICATE KEY UPDATE，重複執行不會造成重複資料。但建議每次匯入前先備份 DB。
匯入後要重新啟動 Express 嗎？
不需要。MySQL 匯入直接寫 DB，Express 讀 DB 時直接拿到新資料，刷新瀏覽器即可。
想清空某張表再重匯？
在 MySQL 執行 TRUNCATE TABLE 表名;，再跑匯入腳本即可。
範例資料（模板裡的 36 筆）會影響既有資料嗎？
會。MGM_casher_details / MGM_invoice_details 等表用 num_vman / invoice_no 當唯一鍵，模板裡的憑證號 / 發票號如果和你既有資料重複會被覆蓋。建議匯入前先 TRUNCATE 對應表。

八、命令參考

匯入

node database/import_excel.js database/finance_data_template.xlsx
node database/import_excel.js "C:\你的路徑\my_data.xlsx"

重新生成模板（已含最新 DB 欄位）

node database/gen_excel_template.js

備份 / 恢復 DB

mysqldump -uroot -pld68315711 ERMM_db > backup.sql
mysql -uroot -pld68315711 ERMM_db < backup.sql

查詢某張表有多少資料

mysql -uroot -pld68315711 ERMM_db -e "SELECT COUNT(*) FROM MGM_finance_summary WHERE bu_no='HM';"

查詢某 BU 某月份資料

mysql -uroot -pld68315711 ERMM_db -e "SELECT * FROM MGM_casher_details WHERE bu_no='HM' AND YYYY_MM='2024/12';"

清空某張表（再重匯）

mysql -uroot -pld68315711 ERMM_db -e "TRUNCATE TABLE MGM_casher_details;"
