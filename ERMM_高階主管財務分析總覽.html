Part 1：系統對高階主管的價值與解決的困擾

核心定位 ERMM 財務模組不是「傳統報表系統」，而是一個以 mgm_finance_summary（200+ 欄位）為核心樞紐的「經營決策支援平台」。 它把散落在 ERP（銷售/採購/發票/現金/銀行/應收應付）的數據自動彙整，即時計算 22+ 項財務比率、5 套風險預警模型、損益平衡點與年度預測，讓高階主管不必再等月底報表、不必再人工拆帳，登入就能看到企業體溫。

1.1 高階主管的核心困擾

😫
數據分散、看不到全貌
銷售在 ERP、採購在另一套、現金在 Excel、銀行貸款在紙本，要拼出一張完整的經營地圖往往要等 3~5 天，決策永遠慢半拍。
📉
利潤去哪了？說不清楚
明明有營收，帳上卻沒錢。毛利、邊際貢獻、固定成本、變動成本混在一起，看不出是哪個產品、哪個客戶、哪個環節在吃掉利潤。
⚠️
風險來了才知道
應收帳款暴增、存貨周轉變慢、負債比攀升，往往等到資金緊繃或銀行預警才發現，沒有即時的紅黃綠燈機制。
🎯
預測與實際永遠對不上
年度預測做了，但每月實際出來後無法快速比對差異、無法即時調整後續月份預算，預測淪為形式。
⏱️
結帳慢、報表慢
每月結帳要 5~7 天，資產負債表、損益表、現金流量表人工編製，數字還可能對不上（資產≠負債+權益）。
🗂️
跨公司比較困難
集團有 HM / SZ / HN 等多個公司別，口徑不一致、匯率不同，要做合併分析或個別診斷非常耗時。

1.2 系統帶來的優點

🔭
一頁儀表板，即時看體溫
Dashboard 整合 KPI 卡片、損益表趨勢、資產負債結構、風險面板，點擊任一卡片即可下鑽明細，從摘要一路追到單筆發票/現金流水。
📐
22+ 財務比率自動計算
償債能力（流動比率、速動比率、負債比）、營運能力（存貨周轉、應收周轉、現金周轉天數）、獲利能力（毛利率、ROA、ROE）、成長能力（銷售/淨利成長率），全部即時算出並標紅黃綠燈。
🚨
5 套風險預警模型
Altman Z-Score（上市公司）、Z2-Score（私人公司）、Z3-Score（非製造業）、BZ 破產概率、JZ 營運能力，搭配 Wolf 模型，自動判定安全/灰色地帶/破產區。
⚖️
損益平衡點（BEP）精算
把成本拆成材料（7 項）、變動費用、固定成本（薪資/租金/利息），算出邊際貢獻率與 BEP，直接告訴你「這個月還差多少訂單就損益兩平」。
🔮
預測 vs 實際對比
支持銷售/成本/現金流三種預測類型，12 個月逐月輸入，實際入帳後自動比對差異，預測線（紫）vs 實際線（綠）同圖呈現。
📑
三大報表一鍵匯出
資產負債表、損益表、現金流量表（間接法）自動產生，並可匯出標準 Excel，解決人工編製與帳不平的問題。
🏢
多公司別統一口徑
HM / SZ / HN 等公司別使用同一套欄位與公式，支援單公司分析與跨公司比較，集團管理一目了然。
🔐
權限分級，安全可控
基於 cams_xuser 的身分驗證（JWT），管理員才能存取使用者管理，一般員工僅能看業務數據，符合內控要求。

3.2 缺口分析與待補全功能清單

🔴
異常自動診斷與原因歸因 P0
現況缺口：系統能標紅燈，但不會告訴主管「為什麼紅」。例如毛利率下滑，主管仍需手動查是哪個產品/客戶/月份造成。

建議補全：當指標異常時，自動展開貢獻度分析（哪個 bu_no、哪個月份、哪個科目拖累最多），並提供「前 3 大原因」摘要。
🔴
行動方案與追蹤閉環 P0
現況缺口：看到問題後，主管需另外開會、派任務，無法在系統內閉環。

建議補全：新增「行動任務」模組，從紅燈指標一鍵建立任務（指派負責人、截止日、改善目標），並在儀表板追蹤進度，讓「發現問題 → 落實行動 → 驗證成效」一氣呵成。
🔴
主動推播與預警通知 P0
現況缺口：需主管主動登入才看得到紅燈，被動等待。

建議補全：當 Z-Score 進入破產區、負債比超標、應收逾期超過 X 天時，自動發送 Email / LINE / 簡訊給對應主管，並附帶建議處置。
🟠
同業標竿與區間比較 P1
現況缺口：只有自身歷史數據，不知道業界水位。

建議補全：導入產業標竿區間（如製造業流動比率合理值 1.5~2.5），在 KPI 旁標示「優於/劣於同業」，讓主管判斷是個案還是趨勢。
🟠
多維度下鑽（產品/客戶/部門） P1
現況缺口：目前下鑽多停留在「單筆發票/現金」，缺乏產品別、客戶別、部門別的彙總視角。

建議補全：從銷售金額可下鑽到「產品毛利排行 / 客戶貢獻度 / 部門費用」，協助主管做資源配置決策。
🟠
現金流量預測與資金排程 P1
現況缺口：現金日記是歷史帳，無法預測未來 3 個月現金水位。

建議補全：結合應收到期、應付到期、貸款還本，產出未來 13 週現金滾動預測，提前預警資金缺口。
🟡
管理會計（責任中心利潤） P2
現況缺口：只有財務會計口徑，缺乏部門/產品的責任利潤。

建議補全：新增費用分攤規則，計算部門邊際利潤 / 產品貢獻利潤，做為考核與資源分配依據。
🟡
集團合併報表與匯率 P2
現況缺口：多公司可切換但無法自動合併，跨幣別需人工換算。

建議補全：支援內部交易沖銷、匯率自動換算、合併資產負債表與損益表，滿足集團管理需求。
🟡
預算編制與彈性預算 P2
現況缺口：預測模組只做金額預估，缺乏預算版本管理與彈性預算。

建議補全：支援年度預算版本、部門預算編制、彈性預算（按實際產量調整），讓預算管理更精準。
🟡
AI 智能問答與解讀 P2
現況缺口：主管需理解財務術語才能讀懂指標。

建議補全：導入自然語言問答，主管可問「為什麼這個月毛利率下滑？」系統自動用淺白語言解讀數據並給建議。

P0 行動方案與追蹤閉環 高 中 第 1 季 從「看到問題」到「解決問題」無縫接軌，決策可落地
P0 主動推播與預警通知 高 低 第 1 季 主管被動變主動，風險一出現即刻收到通知

P2 預算編制與彈性預算 中 中 第 3 季 預算管理從形式變實質，差異可追溯
P2 AI 智能問答與解讀 中 高 第 4 季 降低財務門檻，非財務主管也能讀懂數據

3.4 補全後預期成效

🎯
決策速度提升
從「月底等報表 → 開會找原因 → 派任務」縮短為「即時看紅燈 → 系統告訴原因 → 一鍵派任務」，決策週期從週級壓到日級。
🛡️
風險提前預防
被動善後變主動預防，Z-Score、負債比、應收逾期等指標觸閾值即推播，把財務危機消滅在萌芽階段。
💰
利潤精準管理
透過 BEP + 多維度下鑽，找出吃利潤的產品/客戶/部門，果斷調整資源配置，提升整體獲利率。
💧
現金無虞
13 週現金滾動預測讓主管提前知道何時缺錢，主動安排融資或催收，避免資金斷鏈。
📋
行動可追蹤
每個紅燈都能轉為任務，指派到人、設截止日、追進度，決策不再是空談，成效可驗證。
🌐
集團一頁掌握
合併報表 + 跨公司比較，集團高層不必再彙整十幾份 Excel，登入即見整體營運體溫。
