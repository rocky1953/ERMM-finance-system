ERMM 操作手冊 — CFO

月度结账七步 · 现金预测 · AR 催收 · 数据质检 · 报税 ｜ 由 Markdown 自動產生（唯讀文件）

适用角色：CFO（财务长 / 财务主管）｜适用版本：v3.2（2026-11-05） 系统地址：http://localhost:3008 ｜建议浏览器：Chrome / Edge 本手册覆盖你日常真正要操作的模块：看数、算账、报税、管现金、催收、质检。

CFO 是系统的主要深度使用者：既要看结果（报表），也要管过程（入账、报税、现金、催收），还要保证数据可信（质量扫描）。系统里 50 个入口中，约 30 个与你的职责直接相关。

二、登录与全局操作

  • 登录：http://localhost:3008 → 账号密码 → 仪表板。
  • 公司切换（HM / SZ / HN）：所有页面按 bu_no 取数，切公司即切账套。
  • 月份选择（YYYY-MM）：报表、日报、报税的期间口径。
  • 语言切换：简 / 繁 / 英。
  • 左上角 🏢 ERMM：打开系统架构图。

三、月度结账标准流程（按顺序执行）

① 数据质检（数据质量扫描）→ ② 财务摘要核对 → ③ 三大报表出表
→ ④ 风险预警处理 → ⑤ 财务入账/凭证 → ⑥ 电子化报税 → ⑦ 合并报表

3.1 ① 数据质量扫描（🛠️ 日常作业组）

  • 目的：出报表前先确认底层数据没有脏、缺、重、矛盾。
  • 操作：
    1. 侧边栏「日常作业 · 工作日报」→ 数据质量扫描。
    2. 点击 「开始扫描」，数十毫秒返回。
    3. 按 7 大类 查看结果：财务摘要 6 项 / 发票 5 项 / 银行贷款 3 项 / 现金 1 项 / 预测 2 项 / 勾稽 1 项 / 数据表健康度 8 张表。
    4. 🔴 红色 = 高风险（报表不平衡、金额为空、重复单据），必须处理；🟡 黄色 = 提示项，可择期处理。
    5. 点问题卡片可看受影响记录数与样例，回到对应业务页修正。
  • 注意：当前版本只扫描不自动修复，修复需人工确认，避免误改历史账。

3.2 ② 财务摘要核对（📋 财务分析组）

  • 操作：进入「财务摘要」→ 选公司与月份 → 核对收入、成本、费用、利润、资产、负债六组关键数。
  • 核对要点：与「三大报表」交叉比对；与上月环比看异常跳变。

3.3 ③ 三大报表（📈）

  • 操作：进入「三大报表」→ 切换资产负债表 / 损益表 / 现金流量表 → 选期间。
  • 校验标准：资产负债表必须平衡（系统内 108 个月已全部平衡）；出现不平衡先回 3.1 质检。
  • 导出：页面支持导出，用于对外报送或归档。

3.4 ④ 风险预警（⚠️）

  • 操作：进入「风险预警」→ 查看 5 套模型：Z-Score / Z2 / Z3 / BZ 破产概率 / JZ 营运能力。
  • 判断：灯号红色优先处理；Z-Score 卡片可查看评分公式与区间。
  • 联动：预警项可转「行动追踪」，指派责任人。

3.5 ⑤ 财务入账 / 凭证（📒）

  • 操作：进入「财务入账／报税」→ 按期间筛选待入账单据 → 核对后入账/生成凭证。
  • 注意：入账动作影响报表数字，入账前务必先跑一次数据质量扫描；已入账凭证的更正走冲销，不直接改数。

3.6 ⑥ 电子化报税（🧮）

  • 操作（三种税分四个页签）：
    1. VAT 增值税：选期间 → 取数算税 → 核对销项/进项 → 提交（本地模拟受理，返回受理号与状态）。
    2. CIT 企业所得税：录入/确认收入成本参数（支持人工覆盖）→ 算税 → 提交。
    3. IIT 个人所得税：导入薪资明细（含年终奖单独计税）→ 计算 → 提交。
    4. 录入维护：VAT 调整、CIT 参数、薪资、年终奖的原始录入。
  • 注意：提交为本地模拟受理，不产生真实税局效力；申报记录全程留痕（tax_submit_receipts）。

3.7 ⑦ 合并报表（📋）

  • 操作：选期间 → 查看合并三大报表；系统自动抵销内部交易。
  • 注意：合并口径依赖各公司当月数据齐全，缺一家会导致结果失真 —— 先确认三家都已跑完批次。

四、现金管理（💧 + 🎯）

4.1 现金预测（13 周 + 概率）

  • 操作：
    1. 「经营决策」→ 现金预测 → 默认 13 周滚动预测。
    2. 切换 Monte Carlo 概率模式 → P10 / P50 / P90 区间带 + 负现金概率。
    3. 调整假设（回款天数、付款计划）→ 重算，做 What-if。
  • 判断：安全水位 = 周均流出 ×3（下限 300 万），跌破即标红；概率 >30% 需提前安排融资或压支出。

4.2 AR 智能催收（🎯）

  • 目的：应收款按「该先催谁」自动排序，避免凭感觉。
  • 操作：
    1. 「日常作业」→ AR 智能催收 → 顶部看四个风险等级笔数与金额。
    2. 清单按综合评分排序，显示账龄、逾期天数、金额、客户、等级灯号。
    3. 按灯号处理：
      • 🔴 紧急（≥70）：当日联系，必要时暂停发货
      • 🟠 高优先（50~70）：本周内跟进
      • 🟡 常规（30~50）：常规提醒
      • 🟢 正常（<30）：无需主动催收
    4. 切换公司查看各账套清单。
  • 评分公式：账龄 40% + 逾期 30% + 金额规模 15% + 风险综合 10% + 单笔占比 5%。
  • 注意：清单是建议排序，系统不自动发催收函。

六、每周 / 每月 / 每季动作

  • 每日：看仪表板 AI 摘要 → AR 智能催收清单（🔴 当天处理）。
  • 每周：现金预测看 13 周缺口 → 更新收付款计划 → 预警处理。
  • 每月：按第三章 ①~⑦ 顺序完成结账；报税前跑一次数据质量扫描。
  • 每季：预算执行复盘 + 风险模型复核 + 同业标杆对比。

八、常见问题
