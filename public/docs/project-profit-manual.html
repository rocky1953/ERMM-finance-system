一、用途与数据来源

用于按「公司别 + 客户项目」查看年度预算执行、月度收入/成本归集、毛利与毛利率。

数据来源说明
项目主档mgm_customer_projects（状态 active）页面下拉可选项目
客户→项目映射project_customer_map未映射的出货无法归集项目，成本同步会跳过 UNASSIGNED
出货数量/金额ermm_erp_so（dn_qty>0）收入、成本自动引入的唯一来源
单位成本料件标准成本 → 料件成本率 → 公司销售成本率依次回退，按公司别分别取值
公司别BUSINESS_ID 码表仅 HM/HN/SZ；LTN 为虚拟公司，本页不显示、不参与

二、进入与全局控件

  1. 左侧菜单进入「项目损益」，需账号具备该模块权限。
  2. 顶部控件对全部页签生效：
    • 公司别：全部公司 / HM / HN / SZ。切「全部公司」不会影响其他模块的全局公司别。
    • 月份：决定概览的「本月」数据，以及两个自动引入按钮的目标月份。
    • 操作说明：打开本手册。
    • 刷新：重新加载当前页签。

三、五个页签操作

项目概览

  • 展示本年有预算或 YTD 有收入/成本的项目；卡片为预算、YTD 收入/成本/毛利、超预算项目数（含项目总数、无预算数）。
  • 表格列：预算、YTD、本月、毛利、毛利率、状态；点「明细」跳转该项目 12 个月损益。
  • 状态规则：无数据 → 进行中 → 收入已达标 → 成本超预算（优先级最高）。
  • 成本为 0 但有收入时：毛利显示「—」、毛利率显示「未归集」，顶部出现琥珀色告警。
  • 仅有部分月份有记录时：显示「数据覆盖：YYYY-MM（共 N 个月），YTD 指标为已归集月份合计」；若某些月份有收入无成本，则显示对应月份清单。

项目损益（明细）

  1. 选择「项目」和「年度」。
  2. 查看 3 张卡片（收入/成本/毛利及预算）和 12 个月明细，含当月、毛利率、累计值。
  3. 页头会标注统计范围（全部公司或具体公司别）。
  4. 未来月份与成本缺失月份的毛利显示「—」，避免误读为 0。

年度预算

  1. 选择年度（默认跟随顶部月份所在年）。
  2. 点「➕ 新增/维护预算」，填写 公司别、项目、年度、收入预算、成本预算 后保存。
  3. 同一「公司别 + 项目 + 年度」仅一条，重复保存覆盖；列表中可「编辑」「删除」。
  4. 预算按公司别隔离：HM 的预算不会出现在 HN 视图，「全部公司」为各公司别预算合计。
  5. 在「全部公司」下新增预算时必须选具体公司别，不能挂到 GROUP。

收入确认

  1. 用项目、起止月份筛选，点「查询」。
  2. 手工录入：点「➕ 确认收入」，选择公司别、项目、归属月份，填写金额/单据号/备注。
    • 公司别必选具体公司，无「全部公司」选项。
    • 归属月份默认取当前查询区间的起始月。
  3. 自动引入：点「⬇ 从出货自动引入当月收入」，按顶部月份重新生成自动记录；确认框会写明目标月份。
  4. 表格显示月份、公司别、项目、金额、来源（出货自动/手工确认）、单据号、备注；自动记录可删除，下次同步会重新生成。
  5. 保存后若公司别或月份不在当前筛选内，系统会自动切换公司别/扩展查询区间，保证新记录可见。

成本归集

  1. 用项目、起止月份筛选，点「查询」。
  2. 手工录入：点「➕ 归集成本」，填写公司别、项目、归属月份、成本类型、金额、单据号、备注。
  3. 自动引入：点「⬇ 从出货自动引入当月成本」，按顶部月份、按公司别分别取标准成本/成本率计算；备注会注明所用成本率。
  4. 表格显示月份、公司别、项目、类型、金额、来源（出货自动/手工归集）、单据号、备注、录入人（自动记录显示「系统」）。
  5. 成本/收入暂不支持页面编辑，需删除后重新录入。

四、标准月度操作流程

  1. 维护基础数据：确认新客户已建立项目主档及客户→项目映射。
  2. 确认出货：确保当月出货单已生成且数量、金额正确。
  3. 维护预算：年度初按公司别录入各项目收入/成本预算（年度中可调整）。
  4. 引入收入：顶部月份选目标月 → 收入确认 →「从出货自动引入当月收入」。
  5. 引入成本：成本归集 →「从出货自动引入当月成本」。
  6. 补充手工调整：对无出货依据的成本/收入手工录入（必须选定公司别）。
  7. 复核概览：检查预算达成、成本使用、超预算与「未归集/数据覆盖」提示。
  8. 分析明细：从概览点「明细」查看单项目 12 个月走势。

五、计算口径

指标口径
本月收入/成本顶部月份对应记录合计
YTD 收入/成本所选年度内已归集记录合计
毛利收入 − 成本；成本未归集时显示「—」
毛利率毛利 ÷ 收入；收入或成本为 0 时不计算
收入达成YTD 收入 ÷ 年度收入预算
成本使用YTD 成本 ÷ 年度成本预算
收入自动引入按出货金额汇总，跳过未映射客户的出货
成本自动引入出货数量 × 单位成本，按公司别取价；GROUP 逐公司别计算后分别落库

六、提示与异常处理

  • 「收入已确认但成本尚未归集」：先执行成本自动引入，或手工归集成本。
  • 「仅有收入、未归集成本：YYYY-MM」：补齐所列月份的成本。
  • 「数据覆盖…YTD 为已归集月份合计」：说明该年度只归集了部分月份，YTD 不代表完整年度。
  • 重复同步：仅删除并重建当月、当前公司别范围内的自动记录，手工记录不受影响。
  • 保存后看不到记录：系统已自动切换公司别/扩展月份区间；若仍不可见，检查项目筛选与起止月份。
  • 超预算项目数：统计状态为「成本超预算」的项目；收入达标同时成本超支时按超预算展示。
  • 历史数据：迁移前的旧预算默认归属 HM，如实际属于其他公司别需重新维护。

七、已知限制

  • YTD 目前按所选年度的全部已归集月份合计，不按顶部月份截断；若同年度未来月份已有记录，会提前计入。
  • 成本/收入无编辑功能，只能删除重建。
  • 自动同步依赖出货数据与客户项目映射，两者缺失时不会产生记录且不会报错。
