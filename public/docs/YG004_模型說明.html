一、營運資產模型 Operating Asset Model

模型目的：衡量企業日常營運所投入的資產規模與結構是否健康，判斷短期償債能力與資產配置效率。營運資產過低可能無法支撐營運，過高則資金閒置。

1.1 營運資產額

營運資產額 = 營運資本 + 長期投資
營運資本 = 流動資產 − 流動負債

来源欄位：
current_asset_amt （流動資產）
current_debet_amt （流動負債，若無則取 AP_amt 應付帳款）
LQ_asset_amt （長期投資）
項目說明
指標 IDoa_working_asset
數值類型金額（元）
門檻無固定門檻，以同業比較為主
判讀正值=營運資金充足；負值=短期償債壓力

1.2 營運資產 / 流動負債

比率 = 營運資產額 ÷ 流動負債
項目說明
指標 IDoa_cover_cl
門檻綠燈≥ 1.0（營運資產足以覆蓋流動負債）
門檻黃燈0.5 ~ 1.0（警戒區）
門檻紅燈< 0.5（覆蓋不足，高風險）

1.3 營運資本比率

比率 = 營運資本 ÷ 流動資產
= (流動資產 − 流動負債) ÷ 流動資產
項目說明
指標 IDoa_wc_ratio
門檻綠燈≥ 0.3（流動資產中 30%+ 為淨營運資金）
門檻紅燈< 0.1（流動資產幾乎全被短期負債佔用）
判讀越高表示短期財務彈性越大

1.4 淨值 / 負債總額

比率 = 股東權益淨值 ÷ 負債總額

淨值 = stockholder_amt（優先）
或 captial_stock + captial_reserve + accumulated_amt
負債 = ttl_debet_amt（優先）
或 loan_amt + AP_amt + LT_loan_amt
項目說明
指標 IDoa_equity_debt
門檻綠燈≥ 1.0（淨值 ≥ 負債，財務穩健）
門檻黃燈0.5 ~ 1.0
門檻紅燈< 0.5（負債遠大於淨值，槓桿過高）
模型解讀：四項指標須合併判讀。若營運資產額為負、且淨值/負債 < 0.5，表示企業短期與長期償債能力均不足，需啟動資金規劃。

二、沃爾比重模型 Alexander Wall Model

模型目的：Alexander Wall（1928）提出的綜合信用評分法，選定 7 項關鍵比率，各自設定標準值與權重，以「實際比率 ÷ 標準比率 × 權重」加總得出綜合評分（滿分 100 分）。分數越高代表財務體質越好。

2.1 沃爾綜合評分（滿分 100）

綜合評分 = Σ ( 實際比率_i ÷ 標準比率_i × 權重_i )

各組件明細（7項）：
┌──────────────────────────────┬────────┬────────┬──────────┐
│ 比率項目 │ 標準值 │ 權重(%) │ 計算方式 │
├──────────────────────────────┼────────┼────────┼──────────┤
│ ① 流動比率 │ 2.0 │ 25 │ 流動資產 ÷ 流動負債 │
│ ② 淨值 / 負債 │ 1.5 │ 25 │ 股東權益 ÷ 負債總額 │
│ ③ 總資產 / 固定資產 │ 2.5 │ 15 │ ttl_asset_amt ÷ 固定資產 │
│ ④ 銷貨成本 / 存貨 │ 8.0 │ 10 │ sale_cost_amt ÷ 存貨合計 │
│ ⑤ 銷售額 / 應收帳款 │ 6.0 │ 10 │ sale_amt ÷ AR_amt │
│ ⑥ 銷售額 / 固定資產 │ 3.0 │ 10 │ sale_amt ÷ 固定資產 │
│ ⑦ 銷售額 / 淨值 │ 3.0 │ 5 │ sale_amt ÷ 股東權益 │
└──────────────────────────────┴────────┴────────┴──────────┘

固定資產 = office_amt + building_amt + equipment_amt + vehicle_amt
存貨合計 = stock_P_amt + stock_M_amt + WIP_M_amt

注意：單項得分上限 = 標準值 × 1.5（防止異常高分拉抬總分）
項目說明
指標 IDwall_score
門檻綠燈≥ 100（財務體質優良）
門檻黃燈80 ~ 100（可接受，需關注）
門檻紅燈< 80（財務體質偏弱）

2.2 淨值 / 負債（標準 1.50）

比率 = 股東權益 ÷ 負債總額
（與營運資產模型 1.4 相同公式，但在此用於 Wall 評分組件展示）
項目說明
指標 IDwall_de
標準值1.50
權重25%（7 項中最高）

2.3 總資產 / 固定資產（標準 2.50）

比率 = ttl_asset_amt ÷ (office_amt + building_amt + equipment_amt + vehicle_amt)
項目說明
指標 IDwall_af
標準值2.50
權重15%

2.4 銷售額 / 淨值（標準 3.00）

比率 = sale_amt ÷ 股東權益
項目說明
指標 IDwall_se
標準值3.00
權重5%
模型解讀：Wall 模型適合製造業與貿易業。綜合評分 < 80 時，可逐項檢查哪項比率偏離標準最多，針對性改善。若多項同時偏低，代表整體財務結構有系統性問題。

三、A值模型 Argenti A-score Model

模型目的：Argenti（1976）提出的破產預測模型，以「管理缺陷 + 會計錯誤 + 破產徵兆」三維度累計分數，分數越高代表破產風險越大。本系統以財務數據代理量化各構面，非問卷調查版。

注意：原始 Argenti 模型部分指標為質化判斷（如管理品質、會計造假），本系統以可量化財務比率代理，分數為近似值，僅供預警參考。

3.1 管理缺陷代理分（0~43）

構面 A = 以下條件加總（每項觸發即加分）：
┌──────────────────────────────────────────┬────────┐
│ 觸發條件 │ 配分 │
├──────────────────────────────────────────┼────────┤
│ 淨值/負債 < 0.3（槓桿過高） │ +10 │
│ 流動比率 < 1.2（短期償債弱） │ +8 │
│ 利息保障倍數 < 3（利潤+利息 / 利息 < 3） │ +9 │
│ ROE < 5%（利潤/淨值 < 5%） │ +8 │
│ 銷售額年減 > 5%（與前月比較） │ +8 │
├──────────────────────────────────────────┼────────┤
│ 最高合計 │ 43 │
└──────────────────────────────────────────┴────────┘

利息保障倍數 = (sale_exp_amt + interest_amt) ÷ interest_amt
ROE = sale_exp_amt × 100 ÷ 股東權益
項目說明
指標 IDa_deficiency
門檻黃燈≥ 10（管理面有瑕疵）
門檻紅燈≥ 20（管理面嚴重缺陷）

3.2 會計錯誤代理分（0~15）

構面 B = 以下條件加總：
┌──────────────────────────────────────────┬────────┐
│ 觸發條件 │ 配分 │
├──────────────────────────────────────────┼────────┤
│ 現金比率 < 5%（(現金+存款) / 流動負債） │ +8 │
│ 應收帳款天數 > 90 天 │ +7 │
├──────────────────────────────────────────┼────────┤
│ 最高合計 │ 15 │
└──────────────────────────────────────────┴────────┘

現金比率 = (cash_amt + deposite_amt) ÷ 流動負債 × 100
應收天數 = 365 ÷ (銷售額 ÷ AR_amt)
項目說明
指標 IDa_accounting
門檻黃燈≥ 5
門檻紅燈≥ 10

3.3 破產徵兆代理分（0~42）

構面 C = 以下條件加總：
┌──────────────────────────────────────────┬────────┐
│ 觸發條件 │ 配分 │
├──────────────────────────────────────────┼────────┤
│ 營業虧損（operation_profit 或 sale_exp < 0）│ +15 │
│ 營運資金為負（流動資產 < 流動負債） │ +12 │
│ Z2 值 < 1.1（落入破產區） │ +15 │
├──────────────────────────────────────────┼────────┤
│ 最高合計 │ 42 │
└──────────────────────────────────────────┴────────┘
項目說明
指標 IDa_symptom
門檻黃燈≥ 10
門檻紅燈≥ 20

3.4 A值總分（>25 高風險）

A 值總分 = 管理缺陷分(A) + 會計錯誤分(B) + 破產徵兆分(C)
範圍：0 ~ 100（43+15+42）
項目說明
指標 IDa_total
門檻綠燈≤ 18（安全）
門檻黃燈18 ~ 25（警戒區）
門檻紅燈> 25（高破產風險）
注意A值為越高越危險（與 Z / Wall 模型相反）
判讀方向：與 Z 模型和 Wall 模型相反，A 值越高越危險。總分 > 25 應立即啟動財務危機應變流程；18~25 須逐項檢查哪個構面失分最多，制定改善計畫。

六、HM 2025/06 實例計算

以 HM 公司 2025 年 6 月資料為例，展示各模型計算過程與結果：

6.1 原始數據（HM 2025/06）

欄位數值欄位數值
current_asset_amt2,651,260.14current_debet_amt3,631,675.83
ttl_asset_amt7,850,960.00ttl_debet_amt3,844,780.00
stockholder_amt3,458,140.00sale_amt32,966,679.60
sale_exp_amt1,727,578.94interest_amt283,721.00
cash_amt + deposite_amt1,497,860.00AR_amt8,015,760.00
固定資產合計3,152,400.00存貨合計623,620.00

6.2 營運資產模型計算

營運資產額 = (2,651,260 − 3,631,676) + 0 = −980,416 🔴 負值
營運資產/流動負債 = −980,416 ÷ 3,631,676 = −0.27 🔴
營運資本比率 = −980,416 ÷ 2,651,260 = −0.37 🔴
淨值/負債 = 3,458,140 ÷ 3,844,780 = 0.90 🟡 警戒

6.3 沃爾比重模型計算

① 流動比率 = 2,651,260 ÷ 3,631,676 = 0.73 → 0.73/2.0×25 = 9.1
② 淨值/負債 = 3,458,140 ÷ 3,844,780 = 0.90 → 0.90/1.5×25 = 15.0
③ 總資產/固定資產 = 7,850,960 ÷ 3,152,400 = 2.49 → 2.49/2.5×15 = 14.9
④ 銷貨成本/存貨 = (sale_cost) ÷ 623,620 → 假設 24M/623K = 38.5 → cap 3.75×10 = 37.5
⑤ 銷售額/應收 = 32,966,680 ÷ 8,015,760 = 4.11 → 4.11/6.0×10 = 6.9
⑥ 銷售額/固定資產 = 32,966,680 ÷ 3,152,400 = 10.46 → cap 4.5×10 = 45.0...
⑦ 銷售額/淨值 = 32,966,680 ÷ 3,458,140 = 9.53 → cap 4.5×5 = 22.5

綜合評分 ≈ 41.7 🔴 （< 80，財務體質偏弱）

6.4 A值模型計算

管理缺陷：
淨值/負債 = 0.90 ≥ 0.3 → 不觸發 (+0)
流動比率 = 0.73 < 1.2 → 觸發 (+8)
利息保障 = (1,727,579 + 283,721) ÷ 283,721 = 7.09 ≥ 3 → 不觸發 (+0)
ROE = 1,727,579 ÷ 3,458,140 × 100 = 50% ≥ 5% → 不觸發 (+0)
→ 缺陷分 = 8

會計錯誤：
現金比率 = 1,497,860 ÷ 3,631,676 × 100 = 41% ≥ 5% → 不觸發 (+0)
應收天數 = 365 ÷ 4.11 = 89 天 ≤ 90 → 不觸發 (+0)
→ 會計錯誤分 = 0

破產徵兆：
sale_exp = 1,727,579 > 0 → 不觸發 (+0)
流動資產 < 流動負債 → 觸發 (+12)
Z2（由 Altman 模型算出，HM 約 1.5）≥ 1.1 → 不觸發 (+0)
→ 破產徵兆分 = 12

A 值總分 = 8 + 0 + 12 = 20 🟡 警戒區
結論：HM 2025/06 三模型綜合判讀：
• 營運資產模型 → 🔴 營運資金為負，短期償債壓力大
• 沃爾比重 → 🔴 綜合評分偏低，多項比率未達標準
• A值模型 → 🟡 總分 20 在警戒區，主因為流動比率不足

建議：增加流動資產（收回應收、處分閒置資產）或降低流動負債（展延付款），改善流動比率至 1.2 以上。
