ERMM 操作手冊 — CEO

看全局 · 抓方向 · 定資源｜每日 5 分鐘例行 ｜ 由 Markdown 自動產生（唯讀文件）

适用角色：CEO（总经理 / 董事长）｜适用版本：v3.2（2026-11-05） 系统地址：http://localhost:3008 ｜建议浏览器：Chrome / Edge 本手册只写你实际会点到的地方：菜单名、页面名、操作顺序。技术细节不在本手册范围。

CEO 在系统中的角色是看全局、抓方向、定资源，不是录单据、不是做账。因此你的日常只有三类动作：

  1. 看一眼：仪表板、战情看板、每日 AI 摘要 —— 30 秒掌握公司今天的状态。
  2. 问一句：AI 问答 —— 有疑问直接打字问，不用等财务出报表。
  3. 推一下：行动追踪、预警通知 —— 把该谁做的事派下去，并看是否闭环。

二、登录与界面（每次必用）

  • 登录：打开 http://localhost:3008 → 输入账号密码 → 进入仪表板。登录状态会自动保持，关掉浏览器再开通常无需重登。
  • 左上角 🏢 ERMM：点击可打开系统架构图（了解系统全貌，只读）。
  • 顶部公司切换：HM / SZ / HN —— 切换后所有页面只显示该公司的数据；看合并数据请用「合并报表」。
  • 顶部月份选择：决定你看到的是哪个月的数据。看趋势请在「年度趋势」页切换整年。
  • 右上角语言切换：简中 / 繁中 / English。

三、每日 5 分钟例行（推荐顺序）

顺序 菜单路径 你要看什么 判断标准
1 仪表板 → 每日 AI 执行摘要卡片 昨天发生了什么、今天要盯什么 读 3 行摘要，记下提到的风险项
2 仪表板 → 核心指标卡（营收 / 毛利率 / 现金 / Z-Score） 与上月、与目标对比 红黄灯即为需要关注
3 预警通知（经营决策组） 系统自动推送的异常 红色预警当天处理或指派
4 战情看板 三家公司并排对比 找出明显落后的一家
5 行动追踪 上次交办事项是否闭环 逾期未完成的点名

如果摘要卡片空白，说明当期数据还没生成 —— 点卡片上的「重新生成」即可（需稍等 LLM 返回）。

四、核心操作详解

4.1 仪表板（📊 财务仪表板）

  • 目的：一屏掌握营收、成本、毛利、现金、风险五条主线。
  • 操作：
    1. 选好公司与月份 → 页面自动加载。
    2. 上方是 AI 执行摘要；中部是核心指标卡；下方是趋势图表。
    3. 点击任一指标卡 → 进入对应明细页（如点 Z-Score 看评分区间说明）。
  • 注意：指标卡的数字口径与「三大报表」一致，若两者不一致，请先跑「数据质量扫描」。

4.2 AI 问答（🤖 经营决策组）

  • 目的：用大白话问经营问题，系统检索内部知识库（税务政策、年报、同业数据、数据字典）后给出带依据的回答。
  • 操作步骤：
    1. 侧边栏「经营决策」→ AI 问答。
    2. 在输入框提问，例如：
      • 「这个月毛利率下降的主要原因是什么？」
      • 「三家公司的现金水位谁最紧张？」
      • 「发票丢失怎么补办？」
    3. 回答下方有引用来源，可点开核对；若显示「未找到依据」，说明知识库未收录，请联系财务或 CTO 补充。
    4. 左侧历史会话可继续追问，系统记得上下文。
  • 注意：AI 回答是决策参考，涉及金额与合规结论，以报表和正式文件为准。

4.3 战情看板（⚔️）

  • 目的：三家公司横向对比，快速定位「哪家掉队」。
  • 操作：进入即看，按指标（营收 / 毛利 / 现金流 / 风险）对比；切换月份看不同期间。
  • 建议：每周一固定看一次，作为周会开场。

4.4 多维下钻（🔍）

  • 目的：从汇总数字钻到具体单据，回答「这个数是怎么来的」。
  • 操作：选择公司 → 月份 → 指标（营收 / 成本 / 费用 / 现金）→ 逐层下钻到明细记录。
  • 典型用法：毛利异常时，下钻到成本项 → 找到异常科目 → 再交给财务核查。

4.5 同业标杆（📊）

  • 目的：与行业基准对比，判断「是我们做得差，还是行业都差」。
  • 操作：选择指标与期间 → 查看本公司 vs 行业分位值。
  • 注意：标杆数据由财务维护，若长期未更新可提醒 CFO。

4.6 情景模拟（🎯）

  • 目的：做「如果……会怎样」的推演（如营收下滑 10%、回款延迟 30 天）。
  • 操作：进入页面 → 调整假设参数（营收增减、成本变动、回款天数）→ 提交模拟 → 查看对利润与现金的影响。
  • 建议：重大决策前跑 2~3 个情景（乐观 / 中性 / 悲观），把结论带进决策会。

4.7 合并报表（📋）

  • 目的：看三家公司合并后的整体经营结果（消除内部交易后）。
  • 操作：进入页面 → 选择期间 → 查看合并损益 / 合并资产负债 / 合并现金流。
  • 注意：合并口径由财务维护，如与单家公司相加不一致，属正常的内部交易抵销。

4.8 现金预测（💧）

  • 目的：知道未来 13 周现金够不够用。
  • 操作：
    1. 进入「现金预测」→ 默认显示 13 周点估计曲线。
    2. 切换 Monte Carlo 概率模式 → 显示 P10 / P50 / P90 区间带与「出现负现金的概率」。
  • 建议：只要概率超过 30%，就该让 CFO 准备融资或压缩支出。

4.9 预警通知（🔔）与行动追踪（✅）

  • 预警通知：系统按规则自动生成；红色=需当日处理，黄色=本周内处理。
  • 行动追踪：在此登记你要推动的事项，指定负责人与期限；后续在此看完成状态。
  • 建议：所有口头交办都落一条，避免「说过但没人做」。

4.10 系统文件（🗺️ / 📊 / 🗄️）

  • 仅管理员账号可见可用。内含：系统架构与流程图、高管价值简报、模块数据表关系图。
  • 非管理员点击会提示「你的权限不能使用这个模块功能」。

4.11 滚动预算（🔄）

  • 目的：看未来 12 个月的损益、资产负债、现金流预测，以及 13 周现金是否够用。
  • 操作：进入「滚动预算」→ 选择公司 → 切换损益表 / 资产负债表 / 现金流量表 / 13 周现金 / 假设参数。
  • 你要看的：
    1. 预测期收入与累计净利，是否支撑年度目标。
    2. 期末现金与最低现金余额出现的月份。
    3. 报表平衡差是否接近 0（资产 = 负债 + 权益）。
  • 决策用法：目标与预测有缺口时，让 CFO 调整增长/成本/周转假设，现场对比乐观与保守两版。

4.12 多维盈利（💹）

  • 目的：不只看赚多少，还要看「谁在赚、什么在赚」。
  • 操作：进入「多维盈利」→ 选择公司与期间 → 切换客户 / 产品 / 区域 / 渠道维度。
  • 你要看的：贡献排名前 20% 的客户与产品、毛利率异常偏低的组合，以及「高收入低毛利」的隐性亏损项。
  • 决策用法：定价、返利、资源投放前先看该客户/产品的真实毛利贡献。

4.13 库存周转（📦）

  • 目的：判断库存是否压了过多资金，是否出现呆滞。
  • 操作：进入「库存周转」→ 选择公司与库龄快照 → 看周转概览、库龄结构、呆滞清单、补货建议。
  • 你要看的：
    1. 存货周转率（次/年）与周转天数 DSI，趋势是否恶化。
    2. 呆滞金额及占库存比例（库龄 > 90 天）。
    3. 补货建议中的「暂缓采购」项，避免一边压货一边继续买。
  • 决策用法：DSI 上升 + 呆滞占比上升，就是压降库存的信号；让 COO 对呆滞清单逐项下发处理，CFO 跟踪减值。

五、你的权限范围

能做 不能做（需 CFO / CTO 账号）
查看全部报表与看板 财务入账 / 凭证过账
AI 问答、情景模拟 报税计算与提交
登记与查看行动追踪 系统设定、使用者管理、KPI 门槛
查看预警 批次管线执行、第三方整合配置
查看滚动预算、多维盈利、库存周转 —（只读查看）
打开系统文件（仅管理员账号） 直接修改业务单据

六、每周 / 每月固定动作

  • 每周一：战情看板 + 行动追踪未完成项 → 周会开场 5 分钟。
  • 每月 3 日前：看上月合并报表与月度趋势，确认经营结论；看一次滚动预算与库存周转（DSI、呆滞占比）。
  • 每季度：跑一次情景模拟（季度目标假设）+ 同业标杆对比 + 多维盈利结构复盘，调整资源配置。
  • 随时：看到红色预警 → 当天指派；看到 AI 摘要提到的风险 → 追问 AI 问答。

七、常见问题

现象 处理
仪表板数字与财务报表不一致 让财务跑「数据质量扫描」，先排除脏数据
AI 摘要卡片空白 点「重新生成」；仍失败请联系 CTO 检查 LLM 设定
AI 问答答「未找到依据」 知识库未收录该主题，请 CTO 补充条目
点击系统文件没反应 浏览器缓存旧版，按 Ctrl+Shift+R 硬刷新
看不到某家公司数据 检查顶部公司切换，或该月数据尚未加工（找 COO 跑批次管线）
登录后被踢回登录页 用管理员或有效账号重新登录；持续出现请联系 CTO
