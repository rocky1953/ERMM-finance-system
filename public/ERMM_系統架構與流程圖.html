5️⃣ BEP 損益平衡分析 — 完整數據流

🖥 使用者輸入
公司別 + 年月
→
🌐 GET /api/bep/query
bu_no + YYYY_MM
⬇
🗄 MGM_finance_summary
sale_amt (銷售金額)
🗄 MGM_BEP_threshold
8 項門檻值
🔄 FALLBACK
指定月無資料 → 取最新月
⬇
📐 即時公式鏈（後端計算）
材料     = consumable + packaging + processing + misc_purchase + freight + customs + service_part_comp
變動成本  = 材料 + variable_expense
邊際貢獻  = sale_amt − 變動成本
邊際貢獻率 = 邊際貢獻 / sale_amt × 100%
損益平衡點 = fixed_cost / (邊際貢獻率 / 100)
不足訂單  = sale_amt − 損益平衡點
⬇
🖥 四張公式卡即時顯示
🖥 黃色可編輯材料明細
（即時重算 debounce 250ms）
🔽 點擊明細項目（如「消耗品」）
⬇
🌐 GET /api/bep/detail
item_key + BEP_ITEM_MAP 映射
🗄 mgm_casher_details
查 amt_type 交易明細
⬇
📋 Tab 1: 當月交易明細
日期 / 憑證號 / 摘要 / DR / CR / 累計餘額
📈 Tab 2: 歷史趨勢
12 月 bar chart + MoM 變化

6️⃣ Excel 匯入匯出流程

📥 Excel 匯入

① 前端上傳 .xlsx 檔案（ExcelJS 解析）
② POST /api/batch/import（後端讀取每個 Sheet）
③ Row 2 讀取 field_code 對應 DB 欄位（固定不可變）
④ 驗證：日期轉換（0000-00-00→null）、金額格式、公司代碼大寫
⑤ 使用 UPSERT（ON DUPLICATE KEY UPDATE）避免重複
⑥ 每個 Sheet 獨立 Transaction，失敗自動 Rollback
⑦ 回傳成功筆數 / 失敗筆數 / 錯誤訊息

📤 Excel 匯出

① 使用者點「匯出」按鈕（指定公司 / 年月）
② GET /api/report/export/balance-sheet.xlsx
GET /api/report/export/pl-table.xlsx
GET /api/report/export/cash-flow.xlsx
③ 後端查 finance_summary + 相關表
④ 套用對應公式（calcPL / buildBalanceSheet / cashFlow indirect）
⑤ ExcelJS 生成 .xlsx（含公式、格式）
⑥ 瀏覽器自動下載

前端特性

  • ✓ 原生 HTML5 + CSS3 + ES6（無 React/Vue 框架）
  • ✓ registerPage(id, async fn) 自定義頁面路由引擎
  • ✓ i18n 多語：繁中 / 簡中 / EN
  • ✓ 即時重算 debounce 250ms
  • ✓ Modal 子彈窗（z-index 層級管理 + ESC 優先級）
  • ✓ Pure CSS bar chart（無 chart.js 依賴）
  • ✓ 可編輯材料明細（黃色 editable 區塊）

DB 硬約束（不可違反）

• 日期格式：YYYY-MM-DD；0000-00-00 自動 → null
• 金額：DECIMAL(18,2) 不可加千分位 / $ 符號
• YYYY_MM 格式：YYYY/MM（如 2025/12）
• DB_CR：DR=收入、CR=支出（大寫）
• TX_type：AR / AP（大寫）
• VAT_rate：數字百分比（如 13 代表 13%）
• stock_date：月末最後一天（new Date(Y, M, 0)）
• BEP threshold UNIQUE KEY uq_bu_ym (bu_no, YYYY_MM)
• forecast_detail UNIQUE KEY (bu_no, YYYY_MM, forecast_type)
• ERMM_ARAP_detail UNIQUE KEY (bu_no, YYYY_MM)
• 匯入用 UPSERT（ON DUPLICATE KEY UPDATE）
