# 个人日常工作日报系统 — 功能需求说明

---

## 一、系统菜单概览

系统主菜单「工作日报表」界面包含以下功能按钮（共13个），以网格布局排列：

| 序号 | 按钮名称 |
|------|----------|
| 1 | 工作日报表查询 |
| 2 | 工作未完成分析图 |
| 3 | （其他功能按钮） |

> 注：完整按钮列表以实际系统界面为准。

## 二、功能模块A：工作日报表查询

### A.1 功能入口

- **操作路径**：点击主菜单「工作日报表查询」
- **界面说明**：进入工作日报表管理页面，顶部提供年度、部门、撰写人、日期范围（起止）、状态等筛选条件，中部展示日报数据列表，底部提供分页导航及操作按钮。

**数据列表字段：**

| 列名 | 说明 |
|------|------|
| 序号 | 记录序号 |
| 日期 | 工作日期 |
| 时数 | 工作时长 |
| 工作内容 | 当日工作内容描述 |
| 当日【延误】事情 | 当日延误事项记录 |
| 目前【仍未解决】问题 | 尚未解决的问题记录 |
| 撰写人 | 日报撰写人 |

**底部操作按钮：** 新增、删除、返回

---

### A.2 新增日报

- **触发条件**：在「工作日报表查询」页面点击「新增」按钮
- **界面元素：**

| 区域 | 元素 | 说明 |
|------|------|------|
| 顶部筛选区 | 日期 | 选择日报日期 |
| 顶部筛选区 | From / To | 选择时间范围（08:00~18:00） |
| 顶部筛选区 | (生命平衡轮)时间类别 | 下拉选择时间分类 |
| 主体内容区 | 主要工作项目 | 填写当日主要工作内容 |
| 底部操作区 | 保存 / 操作说明 / 返回 | 功能按钮 |

**日报明细表字段：**

| 列名 | 说明 |
|------|------|
| 序号 | 记录序号 |
| 主要工作项目 | 工作内容描述 |
| 作业时间-From | 开始时间 |
| 作业时间-To | 结束时间 |
| 时间类别 | 工作分类 |
| 小时 | 用时（小时） |
| 客户名称 | 关联客户 |
| 专案代码 | 关联专案 |

**底部补充字段：**

| 字段名 | 说明 |
|--------|------|
| 今天延误事项及原因 | 记录当日延误事项及其原因 |
| 目前尚未解决的事项 | 记录尚未解决的问题 |

---

### A.3 日报日期栏位规则

- **规则说明**：点击「日报的日期栏位」时，系统判断所选日期与当前日期的时间差。
- **输入条件**：仅当所选日期距离当前日期在 **7天以内** 时，才允许输入「今天延误事项及原因」「目前尚未解决的事项」内容。
- **超出范围处理**：超出7天范围的日期不可编辑填写。

---

### A.4 操作说明

点击「操作说明」按钮后，显示以下日报填写规范：

#### 报告时间单位规则

1. **最小报告单位**：至少以 **30分钟** 为报告单位。
2. **多项工作内容**：内容可以包含多项工作内容，且每一项工作内容的使用时间皆小于30分钟。
3. **超时单独成单元**：如果一项工作内容花费超过30分钟以上，必须单独成为一个报告单元。

#### 示例说明

**错误示例（未拆分）：**

| 时间段 | 工作内容 |
|--------|----------|
| from 08:00 to 9:30 | a、检查昨天产品不良，尤其是磁浮旋转框的磁性和包装方式；b、模具房和碎料房6S整改结果复查；c、窗帘磁铁后盖黑色收尾，检查洗机是否干净，保证白色的颜色无色差。 |

**正确示例（拆分为3个报告单元）：**

| 时间段 | 工作内容 |
|--------|----------|
| from 08:00 to 8:30 | a、检查昨天产品不良，尤其是磁浮旋转框的磁性和包装方式； |
| from 08:30 to 9:00 | b、模具房和碎料房6S整改结果复查； |
| from 9:00 to 9:30 | c、窗帘磁铁后盖黑色收尾，检查洗机是否干净，保证白色的颜色无色差。 |

### A.5 时间分类

- **触发条件**：点击「时间分类」按钮
- **界面元素：**

| 筛选条件 | 说明 |
|----------|------|
| 部门 | 选择部门筛选 |
| 撰写人 | 选择撰写人筛选 |
| 年度 | 选择年度 |
| 月份 | 选择月份 |

- **展示内容：**
  - **左侧**：柱状图，展示各时间类别（如「日常工作」「自我实现」等）的使用小时对比
  - **右侧**：3D圆环图，直观展示各时间类别的占比分布

---

### A.6 客户类别分析

- **触发条件**：点击「客户类别分析」按钮
- **界面元素：**

| 筛选条件 | 说明 |
|----------|------|
| 撰写人 | 选择撰写人 |
| 年度 | 选择年度 |
| 月份 | 选择月份 |

- **展示内容：**
  - 3D圆环图展示不同客户类别的使用时间占比
  - 底部状态栏显示总共使用小时数

---

- **图示说明：**

## 三、功能模块B：工作未完成分析图

### B.1 功能入口

- **操作路径**：点击主菜单「工作未完成分析图」
- **界面元素：**

| 筛选条件 | 说明 |
|----------|------|
| 部门 | 选择部门筛选 |
| 年度 | 选择年度 |
| 月份 | 选择月份 |

- **展示内容：**
  - 3D柱状图展示各部门人员的日常报告未完成笔数统计
  - 横轴为人员姓名，纵轴为未完成笔数
  - 每个柱体顶端标注具体数值

---

### B.2 点击人员查看明细

- **触发条件**：在工作未完成分析图中点击具体人员姓名（如「李红娟」）
- **跳转页面**：进入该人员的日常报告延迟明细查询页面

---

### B.3 日常报告延误明细查询

- **页面标题**：【撰写人】【年度-月份】【日常报告延迟】明细查询
- **筛选条件：**

| 筛选条件 | 说明 |
|----------|------|
| 撰写人 | 选择撰写人 |
| 年度 | 选择年度 |
| 月份 | 选择月份 |

- **功能按钮：** 每月工作分析、更新连接资料、查询、返回

- **数据列表字段：**

| 列名 | 说明 |
|------|------|
| 序号 | 记录序号 |
| 工作日期 | 工作日期 |
| 延迟内容 | 延迟的工作内容描述 |
| 仍未解决内容 | 尚未解决的內容描述 |
| 撰写人 | 日报撰写人 |

- **分页导航：** 支持第一页、前10页、页码跳转、后10页、最后一页

---

### B.4 每月工作分析

- **触发条件**：在延误明细页面点击「每月工作分析」按钮
- **展示内容：**
  - 3D柱状图展示「日常工作时间分析」
  - 纵轴为「小时」，横轴为月份（如16-10、16-11、16-12）
  - 图例标识数据系列为「工作小时」

- **筛选条件：**

| 筛选条件 | 说明 |
|----------|------|
| 部门 | 选择部门 |
| 撰写人 | 选择撰写人 |
| 年度 | 选择年度 |
| 月份 | 选择月份 |
| 类别 | 选择类别 |
| 时间类别分析 | 复选框 |
