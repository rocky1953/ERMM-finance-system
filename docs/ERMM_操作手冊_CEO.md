# 一、你的角色定位

CEO 在系统中的角色是**看全局、抓方向、定资源**，不是录单据、不是做账。因此你的日常只有三类动作：

1. **看一眼**：仪表板、战情看板、每日 AI 摘要 —— 30 秒掌握公司今天的状态。
2. **问一句**：AI 问答 —— 有疑问直接打字问，不用等财务出报表。
3. **推一下**：行动追踪、预警通知 —— 把该谁做的事派下去，并看是否闭环。

# 四、核心操作详解

## 4.1 仪表板（📊 财务仪表板）

- **目的**：一屏掌握营收、成本、毛利、现金、风险五条主线。
- **操作**：
  1. 选好公司与月份 → 页面自动加载。
  2. 上方是 **AI 执行摘要**；中部是核心指标卡；下方是趋势图表。
  3. 点击任一指标卡 → 进入对应明细页（如点 Z-Score 看评分区间说明）。
- **注意**：指标卡的数字口径与「三大报表」一致，若两者不一致，请先跑「数据质量扫描」。

## 4.2 AI 问答（🤖 经营决策组）

- **目的**：用大白话问经营问题，系统检索内部知识库（税务政策、年报、同业数据、数据字典）后给出带依据的回答。
- **操作步骤**：
  1. 侧边栏「经营决策」→ **AI 问答**。
  2. 在输入框提问，例如：
     - 「这个月毛利率下降的主要原因是什么？」
     - 「三家公司的现金水位谁最紧张？」
     - 「发票丢失怎么补办？」
  3. 回答下方有**引用来源**，可点开核对；若显示「未找到依据」，说明知识库未收录，请联系财务或 CTO 补充。
  4. 左侧历史会话可继续追问，系统记得上下文。
- **注意**：AI 回答是**决策参考**，涉及金额与合规结论，以报表和正式文件为准。

## 4.3 战情看板（⚔️）

- **目的**：三家公司横向对比，快速定位「哪家掉队」。
- **操作**：进入即看，按指标（营收 / 毛利 / 现金流 / 风险）对比；切换月份看不同期间。
- **建议**：每周一固定看一次，作为周会开场。

## 4.4 多维下钻（🔍）

- **目的**：从汇总数字钻到具体单据，回答「这个数是怎么来的」。
- **操作**：选择公司 → 月份 → 指标（营收 / 成本 / 费用 / 现金）→ 逐层下钻到明细记录。
- **典型用法**：毛利异常时，下钻到成本项 → 找到异常科目 → 再交给财务核查。

## 4.5 同业标杆（📊）

- **目的**：与行业基准对比，判断「是我们做得差，还是行业都差」。
- **操作**：选择指标与期间 → 查看本公司 vs 行业分位值。
- **注意**：标杆数据由财务维护，若长期未更新可提醒 CFO。

## 4.6 情景模拟（🎯）

- **目的**：做「如果……会怎样」的推演（如营收下滑 10%、回款延迟 30 天）。
- **操作**：进入页面 → 调整假设参数（营收增减、成本变动、回款天数）→ 提交模拟 → 查看对利润与现金的影响。
- **建议**：重大决策前跑 2~3 个情景（乐观 / 中性 / 悲观），把结论带进决策会。

## 4.7 合并报表（📋）

- **目的**：看三家公司合并后的整体经营结果（消除内部交易后）。
- **操作**：进入页面 → 选择期间 → 查看合并损益 / 合并资产负债 / 合并现金流。
- **注意**：合并口径由财务维护，如与单家公司相加不一致，属正常的内部交易抵销。

## 4.8 现金预测（💧）

- **目的**：知道未来 13 周现金够不够用。
- **操作**：
  1. 进入「现金预测」→ 默认显示 13 周点估计曲线。
  2. 切换 **Monte Carlo 概率模式** → 显示 P10 / P50 / P90 区间带与「出现负现金的概率」。
- **建议**：只要概率超过 30%，就该让 CFO 准备融资或压缩支出。

## 4.9 预警通知（🔔）与行动追踪（✅）

- **预警通知**：系统按规则自动生成；红色=需当日处理，黄色=本周内处理。
- **行动追踪**：在此登记你要推动的事项，指定负责人与期限；后续在此看完成状态。
- **建议**：所有口头交办都落一条，避免「说过但没人做」。

## 4.10 系统文件（🗺️ / 📊 / 🗄️）

- **仅管理员账号可见可用**。内含：系统架构与流程图、高管价值简报、模块数据表关系图。
- 非管理员点击会提示「你的权限不能使用这个模块功能」。

## 4.11 滚动预算（🔄）

- **目的**：看未来 12 个月的损益、资产负债、现金流预测，以及 13 周现金是否够用。
- **操作**：进入「滚动预算」→ 选择公司 → 切换损益表 / 资产负债表 / 现金流量表 / 13 周现金 / 假设参数。
- **你要看的**：
  1. 预测期收入与累计净利，是否支撑年度目标。
  2. 期末现金与**最低现金余额**出现的月份。
  3. 报表平衡差是否接近 0（资产 = 负债 + 权益）。
- **决策用法**：目标与预测有缺口时，让 CFO 调整增长/成本/周转假设，现场对比乐观与保守两版。

## 4.12 多维盈利（💹）

- **目的**：不只看赚多少，还要看「谁在赚、什么在赚」。
- **操作**：进入「多维盈利」→ 选择公司与期间 → 切换客户 / 产品 / 区域 / 渠道维度。
- **你要看的**：贡献排名前 20% 的客户与产品、毛利率异常偏低的组合，以及「高收入低毛利」的隐性亏损项。
- **决策用法**：定价、返利、资源投放前先看该客户/产品的真实毛利贡献。

## 4.13 库存周转（📦）

- **目的**：判断库存是否压了过多资金，是否出现呆滞。
- **操作**：进入「库存周转」→ 选择公司与库龄快照 → 看周转概览、库龄结构、呆滞清单、补货建议。
- **你要看的**：
  1. 存货周转率（次/年）与周转天数 DSI，趋势是否恶化。
  2. 呆滞金额及占库存比例（库龄 > 90 天）。
  3. 补货建议中的「暂缓采购」项，避免一边压货一边继续买。
- **决策用法**：DSI 上升 + 呆滞占比上升，就是压降库存的信号；让 COO 对呆滞清单逐项下发处理，CFO 跟踪减值。

## 4.14 战略目标 BSC（🎯 经营决策组）

- **目的**：把「公司年度战略」拆成部门与个人目标，并随时看达成率，不让目标停在上次会议上。
- **操作**：
  1. 进入「战略目标」→ 选择公司与期间（年度 / 季度）。
  2. 看三层结构：**公司目标 → 部门目标 → 个人目标**，每层显示权重、目标值、实际值、达成率。
  3. 新增 / 编辑目标：填写目标名称、维度（财务 / 客户 / 流程 / 学习成长）、责任人、目标值、截止日期。
  4. 进度录入后，上层目标自动汇总，不用手工加总。
- **你要看的**：达成率红色（< 80%）的部门与目标，以及连续两期没有进度的目标。
- **决策用法**：季度复盘会上直接开此页，按红黄绿逐项过，现场定资源与责任人。

## 4.15 董事会报告包（📦）

- **目的**：开会前 1 分钟拿到一份可直接分发的董事会材料，不用等财务拼 PPT。
- **操作**：
  1. 进入「董事会报告包」→ 选公司与期间。
  2. 系统自动组包：**财务摘要 + 经营 KPI + 预算执行 + 风险提示**。
  3. 点击导出，生成 PDF / PPTX；导出前可先在线预览各章节。
- **注意**：报告包内容来自当期已加工数据，**导出前确认该月批次已跑完**，否则数字会缺。
- **建议**：董事会前 1 天先导出一次预览版，留给 CFO 核对口径的时间。

## 4.16 组织人效（👥 CEO-05）

- **目的**：回答「人是不是配多了、产出是不是配得上人力成本」。
- **操作**：
  1. 进入「组织人效」→ 选择公司与月份。
  2. 顶部 **12 张 KPI 卡**：编制人数、在职人数、缺编 / 超编、人均产值、人工成本率、人均人工成本等。
  3. 下方 **近 6 个月趋势图**，看人效是升还是降。
  4. 切到「部门编制」页签：按部门维护编制数，支持**一键复制上月**再微调。
- **你要看的**：
  1. 人均产值趋势向下，但人数向上 —— 增员没有带来产出。
  2. 人工成本率高于行业或高于去年同期。
  3. 部门超编但产出未达标。
- **决策用法**：编制审批前先看此页，把「增几个人」换成「人均产值要到多少」。

## 4.17 月结关账进度（📅）

- **入口**：经营决策 → **月结关账**。
- **目的**：知道「这个月的账到底关没关」，避免拿着未关账的数字开会。
- **操作**：选公司与月份 → 看关账日历与任务清单（`closing_calendar` / `closing_task`）→ 每项任务显示负责人、状态、完成时间。
- **你要看的**：本月关账任务完成率、逾期任务、预计关账日。
- **决策用法**：关账未完成前，报表数字只能作参考；月度经营会建议安排在关账完成后。

## 4.18 外汇曝险与税务合规（🌐）

- **入口**：经营决策 → **外汇曝险**；财务预警 → **税务合规**。
- **外汇曝险**：按币别看未结外汇敞口（`fx_exposure_item`）与已做避险（`fx_hedge`），看「敞口覆盖了多少」。
- **税务合规**：看税务优惠适用、法规清单与申报任务完成情况（`tax_compliance_item` / `tax_filing_task`），红色为逾期未办。
- **你的用法**：不需要看明细科目，只看「敞口有没有对冲、税务任务有没有逾期」两件事；有异常直接找 CFO。

## 4.19 AI 治理驾驶舱（🤖 AI 智能组，CTO-09 新增）

- **目的**：全公司 AI 使用情况一眼看清，知道「谁在用 AI、花了多少钱、有没有异常」。
- **操作**：
  1. 侧边栏「AI 智能」→ **AI 治理驾驶舱**。
  2. 6 个页签：

| 页签 | 你要看什么 | 判断标准 |
|---|---|---|
| 概览 | 总调用次数 / 总成本 USD / 平均响应 / 限流次数 | 总成本突增 → 点进去看是哪个模型 / 业务场景 |
| 调用明细 | 逐条 AI 调用（谁、用了哪个模型、花了多少 token） | 非业务时段大量调用 → 可能有滥用或测试脚本跑飞 |
| 成本统计 | 按模型 / 业务 / 时间维度的成本聚合 | 成本集中在某个业务场景 → 评估值不值得 |
| 限流日志 | 被限流的调用记录 | 高频限流 → 该场景 QPS 配置可能不够 |
| 模型计价 | 10 个 LLM 模型的单价配置 | 新模型上线前在此审核单价 |
| 异常检测 | AI 自动标记的异常调用 | 红色异常当天指派 CTO 排查 |

- **注意**：此功能需管理员权限查看；普通高管可看概览和调用明细，不能改模型计价和限流规则。

## 4.20 指标中心统一口径（📊 经营决策组，CTO-06 新增）

- **目的**：保证全公司所有关键指标（ROE、毛利率、DSI、DSO、DPO）只有**一种计算方法**，告别「A 部门说 ROE 15%、B 部门说 12%」。
- **操作**：这个模块**你不需要直接操作**，它是系统底层引擎（`services/metricCenter.js` + `cams_metric_def` 23 指标 7 类别），仪表板、滚动预算、多维盈利、库存周转都统一调用它的计算结果。
- **你需要知道的**：
  1. 所有页面显示的 ROE / 毛利率 / DSI 都走同一套公式了。
  2. 如果你在两个页面看到同一个指标数字不一样 → 不是数据问题，是口径还没统一到新引擎 → 让 CTO 查哪个页面还在走旧逻辑。
- **决策用法**：季度经营会直接拿指标中心的数字，不用再让各部门报自己的版本。

# 六、每周 / 每月固定动作

- **每周一**：战情看板 + 行动追踪未完成项 → 周会开场 5 分钟。
- **每月 3 日前**：看上月合并报表与月度趋势，确认经营结论；看一次滚动预算与库存周转（DSI、呆滞占比）。
- **每月**：看一次组织人效（人均产值、人工成本率、超编情况），有董事会则先导出报告包预览。
- **每季度**：跑一次情景模拟（季度目标假设）+ 同业标杆对比 + 多维盈利结构复盘 + **战略目标达成率复盘**，调整资源配置。
- **随时**：看到红色预警 → 当天指派；看到 AI 摘要提到的风险 → 追问 AI 问答。

# 七、常见问题

| 现象 | 处理 |
|---|---|
| 仪表板数字与财务报表不一致 | 让财务跑「数据质量扫描」，先排除脏数据 |
| AI 摘要卡片空白 | 点「重新生成」；仍失败请联系 CTO 检查 LLM 设定 |
| AI 问答答「未找到依据」 | 知识库未收录该主题，请 CTO 补充条目 |
| 点击系统文件没反应 | 浏览器缓存旧版，按 `Ctrl+Shift+R` 硬刷新 |
| 看不到某家公司数据 | 检查顶部公司切换，或该月数据尚未加工（找 COO 跑批次管线） |
| 登录后被踢回登录页 | 用管理员或有效账号重新登录；持续出现请联系 CTO |
