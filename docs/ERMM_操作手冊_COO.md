# 一、你的角色定位

COO / 部门主管在系统里是**作业执行与异常纠偏**的角色：

1. **交作业**：工作日报每天填、每周审、每月汇总。
2. **看进度**：行动追踪、工作未完成分析 —— 谁没做完、卡在哪。
3. **纠异常**：预警通知、数据质量扫描 —— 问题在当天/本周解决，不拖到月底。
4. **管单据**：ERP 原始单据（采购单、销售订单、交货单）与付款/票据流程。

# 三、每日必做：工作日报

## 3.1 填报日报（📝 工作日报表）

- **目的**：当天做了什么事、花了多久、遇到什么问题，形成可统计的工作量数据。
- **操作步骤**：
  1. 侧边栏「日常作业 · 工作日报」→ **工作日报表**。
  2. 选择日期（默认今天）→ 新增事项：填写事项内容、所属项目、开始/结束时间或工时、完成状态。
  3. 保存 → 当日日报即为「已提交」状态。
  4. 当天漏填可补录（受期间锁定规则限制，跨月通常不允许补）。
- **填写要求**：
  - 一条记录只写一件事，便于后续统计工时。
  - 未完成的事项状态标「未完成」，并写明原因/待办人（后续会自动进入「工作未完成分析」）。
- **常见错误**：只写一句「处理日常事务」→ 无法统计工时，按规范拆成具体事项。

## 3.2 审核日报（部门主管）

- **操作**：进入工作日报表 → 切换到「审核」视图 → 选择下属与日期 → 逐条确认或退回。
- **审核要点**：工时是否合理、事项是否具体、未完成原因是否写清。
- **退回**：填写退回原因，下属修正后重新提交。

## 3.3 工作未完成分析（📊）

- **目的**：找出「反复未完成」的事项与卡点，作为周会输入。
- **操作**：进入页面 → 选公司与期间 → 按人员/项目查看未完成清单与占比。
- **用法**：每周五看一次 → 把高频未完成项转成「行动追踪」并指派。

# 四、执行与追踪

## 4.1 行动追踪（✅ 经营决策组）

- **目的**：把口头交办变成可跟踪的任务，避免「说过就忘」。
- **操作**：
  1. 进入「行动追踪」→ 新增事项：事项内容、负责人、截止日期、优先级。
  2. 负责人完成后更新状态；你在此查看逾期项。
- **建议**：周会前筛出所有逾期项，逐条确认卡点。

## 4.2 预警通知（🔔）

- **目的**：系统按规则自动生成的营运异常提醒（如日报未交、指标偏离、数据异常）。
- **操作**：进入即可查看；红色=当日处理，黄色=本周处理。
- **处理方式**：能当场解决的直接解决；需跨部门协调的转「行动追踪」。

## 4.3 仪表板（📊 财务仪表板）—— 只看不看懂的地方

- **你重点看**：AI 执行摘要（当天要盯什么）、核心指标灯号、预警条数。
- **不需要**深入钻财务科目，那是 CFO 的活；但摘要里提到的运营问题要跟进。

# 五、单据与流程作业

## 5.1 ERP 原始单据（🛒 / 📦 / 🚚 / 📥）

| 模块 | 用途 | 操作要点 |
|---|---|---|
| 采购单 PO | 查采购下单与到货情况 | 按供应商/单据号筛选；状态跟踪 |
| 销售订单 SO | 查接单与出货情况 | 按客户/订单号筛选 |
| SO 交货单 | 查出货明细 | 与 SO 对应核对 |
| PO 暂存 | 待确认的采购单暂存区 | 确认后转入正式 PO |

- **注意**：这些是**原始单据的查询与核对**，录入源头在 ERP 系统；本系统以只读/同步为主，改动请回 ERP 操作，避免两边不一致。

## 5.2 付款与票据（💳 / 📝 / 🏦）

| 模块 | 用途 | 操作要点 |
|---|---|---|
| 付款明细 | 查付款计划与执行 | 按供应商/期间筛选 |
| 票据管理 | 应收应付票据登记与到期提醒 | 到期前处理 |
| 银行贷款 | 贷款台账与还款计划 | 关注还款日与额度 |

- **作业要求**：付款申请前先确认「现金预测」水位（见 5.3），避免周内现金不足。

## 5.3 现金预测（💧 经营决策组）—— 你只需要看结论

- **操作**：进入「现金预测」→ 看 13 周曲线与安全水位；如显示概率模式，看「负现金概率」。
- **你的用法**：安排大额付款前先看一眼，必要时向 CFO 申请调整付款节奏。

## 5.4 应收应付（📐）

- **操作**：进入「应收应付」→ 按客户/供应商查看余额与账龄 → 与 AR 智能催收清单配合使用（催收由 CFO 主导，你负责业务侧配合）。

## 5.5 库存周转与呆滞（📦 经营决策组）

- **入口**：经营决策 → **库存周转**；页头选择公司与库龄快照日期。
- **五个页签**：

| 页签 | 用途 | 你要做的事 |
|---|---|---|
| 周转概览 | 库存金额、周转率/DSI、呆滞占比、库龄结构 | 先看呆滞金额占比与趋势是否恶化 |
| 库龄结构 | 按 0-30 / 31-90 / 91-180 / >180 天分档，可看料件明细 | 找出高金额、长库龄料件 |
| 呆滞清单 | 库龄 > 90 天的料件，含判定原因与建议处置 | 逐项「下发处理」派单 |
| 补货建议 | 目标覆盖天数、补货点、建议补货量 / 暂缓采购 | 补货量 > 0 才安排采购；超储项先消化 |
| 处理记录 | 所有呆滞处理单及状态 | 跟踪责任人按时完成并更新状态 |

- **下发处理流程**：
  1. 在「呆滞清单」点「下发处理」。
  2. 选择处置方式（降价促销 / 退货供应商 / 报废核销 / 转用在制品 / 暂停采购 / 调拨其他公司），填处置数量、预计回收金额、责任人、完成时限。
  3. 确认下发后，到「处理记录」把状态从「待处理」推进到「进行中 / 已完成」。
- **注意**：
  - 库龄来自库存日快照，系统默认选料件最完整的最近日期，避免个别补录日期导致结构失真。
  - 周转率/DSI 来自财务汇总近 12 个月，与库龄快照口径不同，两者结合看。
  - 补货需求优先取销售交货量，无销售数据的原料以采购量近似，仅作参考。
  - 呆滞处置涉及报废/降价时，先与 CFO 确认减值与审批口径。

# 六、批次与数据（作业侧配合）

## 6.1 批次管线（⚙️ 系统组）

- **用途**：把当期原始数据加工成可分析的数据。
- **你的角色**：通常由 IT/财务执行；若你被授权，操作是「选公司与月份 → 执行 → 看每步状态」。
- **重要**：批次没跑完，仪表板、报表、预警都没有当期数据 —— 发现数据缺失先问这一项。

## 6.2 数据质量扫描（🛠️ 日常作业组）

- **用途**：检查数据是否脏、缺、重、矛盾。
- **你的用法**：周报/月报数据异常时跑一次，把结果转给财务或 IT 修复。
- **注意**：只扫描不修复，修复需责任人确认。

# 七、每周 / 每月固定动作

- **每日下班前**：确认本部门日报已全部提交（未交的当日提醒）。
- **每周五**：工作未完成分析 → 筛高频卡点 → 转行动追踪 → 周会同步；库存周转看一次呆滞清单，未下发项当天派单。
- **每周一**：看战情看板对比三家公司，确认本周重点。
- **每月初**：审上月日报汇总，确认工时与产出；配合财务完成数据补录。

# 九、常见问题

| 现象 | 处理 |
|---|---|
| 日报保存失败 | 检查日期是否跨月锁定、必填项是否齐全 |
| 未完成分析里没有我今天的事项 | 日报中该事项需标「未完成」并写原因 |
| 仪表板没有当月数据 | 该月批次未跑完，联系 IT/财务执行批次管线 |
| 预警太多不知从何下手 | 先处理红色（当日），黄色统一在周五批量处理 |
| 库存周转页没有库龄数据 | 该公司无库存日快照，联系财务/IT 确认 `e2_xitems_daily_status` 是否已同步 |
| 呆滞清单为空 | 当前快照无库龄 > 90 天的料件；可切换其他快照日期复核 |
| 补货建议为空 | 当期无近 12 个月出库/采购需求数据，或库存已覆盖补货点 |
| 下发处理单报错 | 确认已选公司与料件；处置方式与数量为必填 |
| 付款后现金紧张 | 付款前先看现金预测水位，与 CFO 协调节奏 |
| ERP 单据在本系统改不了 | 原始单据以 ERP 为准，请回 ERP 修改后同步 |
| 点击系统文件没反应 | 需管理员账号；普通账号会有无权限提示 |
