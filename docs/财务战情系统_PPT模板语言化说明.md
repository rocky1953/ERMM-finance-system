# 财务战情系统 PPT 模板 —— 语言化规格说明

> 用途：把这份说明作为「模板基因」，交给 AI 或设计工具即可复刻同风格的新演示模板。
> 本文件是对《财务战情系统 · CEO/CFO/CTO/COO 需求蓝图》这套 .pptx 版式的形式提炼，只描述「怎么排、怎么配色、每个页型长什么样」，不含具体业务文案。

## 一、整体定位与视觉基调
- **类型**：企业级、管理层汇报型深色点缀 + 浅底卡片的商务模板。
- **基调**：稳重专业。藏蓝为主，暖金为强调点缀，蓝/绿分角色着色，白底承载信息。
- **风格关键词**：卡片矩阵、三级抬头、色条分隔、留白规整、信息密度中高。

## 二、画布与母版
- 幻灯片 16:9，尺寸 1280 × 720 px（EMU 12192000 × 6858000）。
- 页面底色：纯白 `#FFFFFF`（来自母版）。
- 左右版心：内容区左右各留边距 **52.8 px**，正文可用宽 ≈ **1174 px**（x 从 52.8 到 1226.4）。
- 页眉顶栏：每页顶部一条通栏色条，全宽、高 **15.4 px**（内容页为金色，见下）。

## 四、字体与字号层级
- 字体：中文 **微软雅黑**（标题正文同族）；数字/英文与中文同字族。
- 字重：标题类加粗约 37%，正文常规。
- 字号阶梯（pt）：
  - 封面主标题 **40**（白、粗）；结尾主标题 **34**；内容页章节标题 **28**（藏蓝、粗）；
  - kicker 页眉 **13**（蓝、粗）；
  - 卡片/列小标题 **18**（白、粗，深底）或 **15**（卡片头白字）；
  - 正文 **13 / 12 / 11**；强调/标签 **11**；
  - 页脚、页码 **10**（灰）；
  - 结尾行动号召框 **17**。

## 五、通用页面骨架（几乎每页复用）
自上而下固定三段抬头 + 底部页脚：
1. **顶部色条**：通栏 `#E8B44A`，h=15.4，y=0。
2. **kicker**（如 `03 / 章节名`）：x=52.8, y≈36.5, sz=13, 蓝粗。
3. **章节标题**：x=52.8, y≈69, sz=28, 藏蓝粗。
4. **副标题/一句话主张**：x=52.8, y≈132, sz=13, 灰。
5. **主体内容区**：y 从约 192 起，到约 640。
6. **页脚**（左）：`财务战情系统 · … 需求蓝图`，x=52.8, y≈677, sz=10, 灰。
7. **页码**（右）：x≈1181, y≈677, sz=10, 灰。

## 六、页型库（按类型复刻即可生成新模板）
### A. 封面页
- 满屏深底 `#0B1F3A`（overlay 1280×720）+ 底部暖金分隔线（y≈566, h≈7.7）。
- 小标（金、粗、16pt）在 y≈163；主标题（白、40pt、粗，两行）y≈216 起；
- 一句话主张 + 落款（日期/规划名）置于标题下方与底部。

### B. 概念/要点四栏页
- 抬头同骨架；主体为 4 组「要点标题 + 短释」横向/网格排布。
- 每组含一个加粗小词（如四动词式：看得见/看得懂…）+ 一句解释 + 一个加粗短语标签。

### C. 「角色需要什么」四行卡页（核心信息页）
每行三段式卡片，纵向 4 行（y≈192/303/414/526，行高 96，行距 ~114）：
- 左：深色 `#0B1F3A` 卡 w=240，内 18pt 白粗标题（约 4 字）。
- 中：浅蓝 `#F2F6FB` 卡 w=633.6（x≈307.2），内 13pt 正文描述（约 25–30 字，1–2 行）。
- 右：浅绿 `#EAF3EC` 卡 w=268.8（x≈955.2），内 11pt 绿字，格式为「对应模块」+ 模块名（两行）。
- 底部一行「X 视角原则：… · … · …」强调句（蓝、13pt 粗）。

### D. 「系统如何满足角色」三卡 + 承诺页
- 上部三栏并列卡片（每栏 x≈52.8/451.2/849.6，w=379.2）：
  - 浅蓝主体卡 `#E6EEF8` h≈201.6，顶部压一条蓝头 `#1F6FC4` h≈40.3；
  - 头内 15pt 白粗编号标题（① … / ② … / ③ …），体内 12pt 墨色说明（两行，约 40–55 字）。
- 下部通栏深底承诺块 `#0B1F3A`（x=52.8, y≈422.4, w=1176, h≈211）：
  - 金色 15pt 粗小标题「给 X 的交付承诺」+ 3 条 13pt 白字要点（以 `▪` 起首）。

### E. 需求全景（三列角色页）
- 标题下三列并列（每列 x≈53/456/859，w=384）：
  - 列头色条（蓝 `#1F6FC4` / 绿 `#2EA86B` / 金 `#E8B44A`，h=60，内 18pt 白粗角色名）；
  - 其下一行灰字「核心关注：…」；
  - 其下浅蓝卡 `#F2F6FB`（h≈307），内 13pt 以 `▪` 起首的 4 条要点。

### F. 协同/体系放射页
- 中央深色方块 `#0B1F3A`（288×288，居中 x≈496）承载系统名（22pt 白粗，两行）；
- 周边 3 个角色小卡（211×120）分色蓝/绿/金，围绕中心；
- 左侧一条竖向「机制」标签浅蓝长条（x≈53, w=139, h=442）；
- 底部一行灰字流程示例（用 `→` 串联）。

### G. 路线图（三阶段页）
- 三栏并列（阶段标题色条 + 阶段名粗标 + `▪` 要点列表），从左到右递进。

### H. 价值/指标卡阵页
- 多张指标卡网格，每卡：大号数字/符号（如 `T+30 → T+0`、`≤ 5 天`）+ 指标名 + 一句量化说明；
- 底部一行总结强调句。

### I. 结尾行动号召页
- 满屏深底 + 暖金分隔线（呼应封面）；
- 主标题 34pt 白粗（两行）+ 一段 18pt 白字主张（两行）；
- 一个强调框（442×72）放「行动号召」，下方一行 13pt 建议句。

## 七、内容填充与字数预算规则（复刻新模板时遵守）
1. **以原文长度为上限**：标题、卡片描述、要点均不要超过对应槽位原文字数——框尺寸与字号固定，超字数会溢出且不易被发现。
2. **多行卡片按原段落数对齐**：承诺/说明类卡片保留原有段落数，逐段填一句话。
3. **配色随角色绑定**：新增一个业务角色时，给该角色分配一个主色（沿用蓝/绿/金体系，或从主题 accent 取新色），其「列头色条 / 卡片头 / 强调」统一用该色。
4. **页型即插槽**：生成新模板时，先选页型（C/D/E…），把版式骨架与坐标原样保留，仅替换文字与角色色。
5. **保持三级抬头一致**：kicker → 章节标题 → 一句话主张 的顺序、字号、颜色全套统一，页脚左 + 页码右固定。

## 八、如何用这份说明生成新模板
- 把「二～五」作为全局主题变量（画布、色板、字体、页眉页脚骨架）灌入模板引擎；
- 把「六」的每个页型作为可复用版式，按「七」的字数预算填入新主题文案；
- 需要新增一个「角色/业务域」时，复制页型 C + 页型 D 各一页，替换标题、要点与角色色即可保持体系一致。
